# Prostut Question Assets & Diagrams CDN

This repository hosts question stimuli, diagrams, tables, circuit schematics, and model answer images for the Prostut educational web app.

Assets are served globally via jsDelivr CDN and raw GitHub:
- `https://cdn.jsdelivr.net/gh/<owner>/<repo>@main/questions/collected/...`
- `https://raw.githubusercontent.com/<owner>/<repo>/main/questions/collected/...`
